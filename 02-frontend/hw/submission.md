## Next.js vs raw HTML/CSS
HTML/CSS are foundational technologies that help bring styling/elements to applications. However, next.js is a full stack framework that helps generate HTML/CSS through a server.


## How the tools fit together
By writing the code in page.tsx for the layout, the HTML/CSS is then generated by the server using Next.js to display on the browser. Typescript also checks for type errors.

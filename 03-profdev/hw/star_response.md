# STAR response

**Question:** Tell me about a time you faced a challenge while working on a project or with a team. What did you do, and what was the result?

## Situation
I was creating a club management software for my high school where I worked with 2 of my other friends.


## Task
We all had just started getting into collaboration when coding so we were figuring out how to commit our code without creating merge conflicts with somebody else.


## Action
We still ran into merge conflicts and we weren't sure what to do. We then communicated with each other so we could make sure that the things we're working with are separate.


## Result
We were able to do our tasks without interfering with each other's code.
